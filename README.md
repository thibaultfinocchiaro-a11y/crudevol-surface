# CrudeVol Surface

Application pédagogique permettant d’explorer une surface de volatilité implicite pour les options sur futures Brent et WTI.

## Fonctionnalités

- surface de volatilité sous forme de heatmap et de vue 3D ;
- smile et structure par maturité ;
- comparaison Brent–WTI ;
- scanner de relative value ;
- recalibrage interactif ;
- définitions contextuelles et lexique accessible.

Les données actuellement affichées sont synthétiques et servent uniquement à la démonstration.

## GitHub Pages

Le workflow inclus publie automatiquement le contenu du dossier `dist` sur GitHub Pages à chaque mise à jour de la branche `main`.
